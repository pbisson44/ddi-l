# Parcours d'apprentissage par profil

!!! info "Ces parcours font désormais partie du programme de formation"
    Le site utilise un seul ensemble de profils d'apprenants, dans le tableau
    [Par où commencer ?](../curriculum/index.md#par-ou-commencer) du
    programme : étudiants, chercheurs, archivistes, personnel d'INS et
    développeurs qui automatisent les contrôles DDI.

    - Le parcours **nouveaux intégrateurs** correspond au début du programme :
      les modules 2 à 7 installent `ddi-l`, construisent une étude et la
      valident depuis Python et en ligne de commande.
    - Le parcours **équipes d'automatisation avancée** est le
      [parcours automatisation](../curriculum/index.md#parcours-automatisation)
      du programme.
