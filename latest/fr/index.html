Pourquoi ddi-l¶

Le DDI (Data Documentation Initiative) est la norme internationale qu'utilisent les organismes statistiques, les archives de données et les chercheurs pour décrire les enquêtes et les jeux de données : ce qui a été demandé, ce que signifie chaque variable et qui a été interrogé. Écrite en XML, cette documentation est très imbriquée et pleine de renvois. ddi-l vous permet de la rédiger et de la vérifier en Python plutôt que d'éditer le XML à la main.

  • Écrire du DDI en Python

    Créez des études, des questions, des variables et des listes de codes comme des objets Python. ddi-l écrit le XML DDI 3.3 et chaque renvoi entre les éléments.

  • Valider toute version 3.x

    Vérifiez des fichiers DDI Lifecycle 3.1, 3.2 et 3.3 selon les schémas officiels, pour contrôler les fonds plus anciens avec le même outil.

  • Analyser ce que les schémas laissent passer

    Repérez les éléments sans libellé, les renvois vers des éléments inexistants, les traductions manquantes et les conditions qui ne peuvent jamais être vraies.

  • Partir d'un tableur

    Décrivez une étude dans des fichiers CSV ou un classeur Excel, puis chargez-la en DDI d'un coup.

  • Travailler avec d'autres outils

    Exportez du JSON-LD pour les données liées, modifiez des exports Colectica, faites entrer des fichiers DDI-Codebook, et faites tout cela depuis R ou par HTTP.

  • Apprendre en pratiquant

    Un cours gratuit en français et en anglais, de « qu'est-ce que les métadonnées ? » à un paquet DDI validé et versionné. Aucune expérience du DDI ni du XML n'est requise.

Démarrage rapide¶

Installez ddi-l depuis PyPI. L'extra full ajoute le moteur lxml, plus rapide (voir Installation).

pip install ddi-l

uv add ddi-l
uv run ddi --help

poetry add ddi-l
poetry run ddi --help

Créez une étude, ajoutez une question et la variable qui enregistre sa réponse, puis enregistrez-la :

import ddi_l as ddi

# Créer une nouvelle étude
doc = ddi.new_study(title="Enquête ménages", agency="example.org")

# Ajouter une question et la variable qui enregistre sa réponse. `label=` est
# facultatif, mais `ddi lint` signale chaque élément qui n'en a pas.
q_age = doc.add_question(text="Quel âge avez-vous ?", label="Question sur l'âge")
doc.add_variable(name="Age", question=q_age, label="Âge en années")

# Enregistrer en XML
doc.save("enquete-menages.xml")

Rouvrez-la plus tard :

# Ouvrir une étude existante
doc = ddi.open_ddi("enquete-menages.xml")

for v in doc.variables:
    print(v.identifier)

Vérifiez le fichier en ligne de commande. Les deux commandes se terminent avec le code 0 quand le fichier est propre, ce qui permet de les utiliser dans des scripts et en CI :

ddi validate enquete-menages.xml
ddi lint enquete-menages.xml

Le guide d'utilisation montre comment s'articulent les parties d'une étude et fait le tour de l'API Document.
