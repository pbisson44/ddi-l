    Toutes les solutions des exercices et les réponses aux quiz du programme, sur une seule page, pour les instructeurs. Les apprenants qui suivent un module peuvent plutôt ouvrir la réponse sous chaque exercice et chaque question.

    Module 1 : Qu'est-ce que les métadonnées et pourquoi sont-elles importantes ?¶

    Exercices¶

    Exercice 1

    Trois de ces questions, ou d'autres semblables :

    1. Que signifie chaque colonne ? (A est-elle un âge ? En années ou en mois ?)
    2. Dans quelle unité est la colonne C ? (Dollars ? Euros ? Par année ou par mois ?)
    3. Qui a été interrogé ? (Des étudiants ? Des adultes ? Tout le monde ?)
    4. Quand les données ont-elles été collectées ?

    Exercice 2

    1. Les métadonnées sont des informations qui décrivent des données : ce qu'elles signifient, d'où elles viennent et comment elles ont été collectées.
    2. Métadonnées : deux éléments parmi le titre « Campus Sleep Study 2025 », la date de collecte (septembre 2025), la population (étudiants de première année), le nom de colonne sleep_hrs ou sa signification (heures de sommeil lors d'une soirée de cours typique). Donnée : l'une des valeurs 7, 6 ou 8.

    Exercice 3

    1-c, 2-d, 3-b, 4-a.

    • Trouvable (c) : le catalogue ne peut trouver que ce qui est décrit dans des champs structurés.
    • Accessible (d) : un format standard et ouvert ne demande aucun logiciel spécial.
    • Interopérable (b) : une liste de codes partagée donne le même sens au même code dans les deux enquêtes, ce qui permet de combiner les données.
    • Réutilisable (a) : un nouvel utilisateur sait exactement ce que contiennent les données.

    Exercice 4

    Par exemple : « DDI, la Data Documentation Initiative, est une norme internationale pour décrire les enquêtes, les recensements et les jeux de données en XML. Les instituts nationaux de statistique, les archives de données, les universités et les équipes de recherche l'utilisent pour que d'autres puissent trouver, comprendre et réutiliser leurs données. »

    Deux de ces types d'organisations suffisent : instituts nationaux de statistique, archives de données ou bibliothèques nationales, universités et leurs dépôts de recherche, équipes de recherche.

    Exercice 5

    Oui : 1, 3 et 5. Non : 2 et 4.

    Par exemple : « ddi-l crée, lit, modifie et valide des métadonnées DDI à partir de Python, mais il ne recueille pas les réponses d'enquête. »

    Quiz¶

    Question 1 (O1) : Un tableur contient une colonne intitulée Age (years) avec les valeurs 34, 28 et 45. Lequel de ces éléments est une métadonnée ?

    B. Les métadonnées sont des informations sur les données. L'en-tête vous dit ce que les chiffres signifient et comment ils sont mesurés. Les valeurs elles-mêmes, et tout ce qu'on en calcule, sont des données.

    Question 2 (O2) : Un collègue vous envoie un tableau avec les colonnes A, B et C, sans aucune note. La colonne C contient des valeurs comme 52000. Vous voulez publier le revenu moyen. À quelle question devez-vous d'abord répondre ?

    D. Sans savoir que C est un revenu, et s'il est en dollars ou en euros, par année ou par mois, toute moyenne publiée pourrait être fausse. Les autres questions ne changent pas le sens des chiffres.

    Question 3 (O3) : Quelle phrase décrit le mieux DDI ?

    A. DDI est une norme : un ensemble de règles convenues pour la documentation. L'option C confond DDI avec les outils ; ddi-l est un paquet Python qui travaille avec DDI, et il ne calcule pas de statistiques.

    Question 4 (O4) : Votre enquête et une enquête française utilisent la même liste de codes DDI pour le genre, ce qui permet de fusionner les deux jeux de données. Quel principe FAIR cela soutient-il le plus directement ?

    C. Interopérable signifie que les données fonctionnent avec d'autres données. Une liste de codes partagée donne à chaque code le même sens dans les deux jeux de données, qui peuvent alors être combinés et comparés.

    Question 5 (O4) : Un catalogue de données lit le titre, l'agence et les concepts de votre fichier DDI, si bien qu'une recherche sur 'enquête santé mentale' affiche votre jeu de données. Quel principe FAIR cela soutient-il ?

    A. Trouvable signifie que les gens peuvent découvrir les données. Les champs DDI structurés donnent aux catalogues une base fiable à indexer et à interroger.

    Question 6 (O5) : Laquelle de ces tâches ddi-l NE fait-il PAS ?

    B. ddi-l travaille avec des métadonnées : il crée, lit, modifie et valide des documents DDI. Recueillir des réponses est le rôle d'un outil d'enquête.

    Module 2 : Préparer votre environnement Python¶

    Exercices¶

    Exercice 1

    Par exemple, Python 3.12.3 : oui, car 3.12 est 3.11 ou plus récent. Si vous voyez Python 3.10.12 ou plus ancien, la réponse est non : installez un Python plus récent depuis https://www.python.org/downloads/ avant de continuer.

    Exercice 2

    La dernière ligne commence par Successfully installed et mentionne ddi-l-... parmi les paquets (la version peut varier). Si les paquets étaient déjà installés, pip affiche plutôt Requirement already satisfied. Dans les deux cas, vous êtes prêt. Une ligne qui commence par ERROR signifie que l'installation a échoué.

    Exercice 3

    La version installée, par exemple 0.1.0 ou plus récente. Si vous voyez plutôt ModuleNotFoundError, ddi-l n'est pas installé dans ce Python : revenez à l'exercice 2.

    Exercice 4

    1. validate (« Validate an XML document against the DDI schema. »)
    2. lint (« Lint a DDI document and report findings as JSON. »)
    3. versions (« List supported DDI schema releases. »)

    Exercice 5

    1. Python REPL : c'est le moyen le plus rapide d'exécuter une ligne que vous n'avez pas besoin de garder.
    2. Fichier script : il garde votre code, et python my_script.py le réexécute depuis le début.
    3. Notebook : il montre les notes, le code et les résultats ensemble, pas à pas.

    D'autres choix conviennent si votre raison tient ; par exemple, un notebook garde aussi votre code pour la tâche 2.

    Quiz¶

    Question 1 (O1) : python --version affiche Python 3.10.12. Que devez-vous faire avant d'installer ddi-l ?

    B. ddi-l nécessite Python 3.11 ou plus récent, et 3.10 est plus ancien. Installez un Python plus récent, puis installez ddi-l avec celui-ci.

    Question 2 (O2) : La dernière ligne de pip install ddi-l pandas openpyxl indique Requirement already satisfied. Qu'est-ce que cela signifie ?

    D. Requirement already satisfied signifie que le paquet est déjà là. Une installation qui échoue se termine par une ligne qui commence par ERROR.

    Question 3 (O3) : Vous exécutez import ddi_l as ddi et obtenez ModuleNotFoundError: No module named 'ddi_l'. Quelle est la cause la plus probable ?

    A. Python ne trouve pas le paquet : il n'est donc pas installé pour ce Python. Relancez pip install ddi-l, ou python3 -m pip install ddi-l si vous démarrez Python avec python3. L'option B n'est pas du Python valide : un trait d'union ne peut pas figurer dans un nom d'import, c'est pourquoi le module s'appelle ddi_l.

    Question 4 (O4) : Vous voulez vérifier un fichier par rapport au schéma DDI depuis le terminal. Quelle commande de la liste ddi --help utilisez-vous ?

    C. Sa description dit « Validate an XML document against the DDI schema. » roundtrip réécrit un fichier, to-json le convertit et serve lance l'API HTTP.

    Question 5 (O5) : Vous allez construire une étude sur plusieurs jours et voulez tout réexécuter depuis le début avec une seule commande après chaque modification. Quel espace de travail convient le mieux ?

    B. Un fichier script garde votre code, et une seule commande le réexécute en entier. Le REPL oublie ce que vous avez tapé quand vous le fermez.

    Module 3 : Créer votre première étude DDI¶

    Exercices¶

    Exercice 1

    import ddi_l as ddi

doc = ddi.new_study(title="Student Well-Being Survey", agency="university.edu")

q1 = doc.add_question(text="What is your age?")
q2 = doc.add_question(text="How would you rate your health?")
q3 = doc.add_question(text="How many hours do you sleep per night?")

print(f"Questions: {len(doc.questions)}")  # -> Questions: 3
for q in doc.questions:
    print(q.identifier)

doc.save("well-being.xml")

    Exercice 2

    Le texte de la question se trouve dans un élément <d:Text>, à l'intérieur de <d:LiteralText>, lui-même dans <d:QuestionText> :

    <d:Text xml:lang="en" isPlainText="true">What is your age?</d:Text>

    Exercice 3

    from ddi_l.models.base import InternationalString

print(f"Problèmes de schéma : {len(doc.validate())}")  # -> Problèmes de schéma : 0
print(f"Constats de lint : {len(doc.lint())}")  # -> Constats de lint : 3

q1.labels.append(InternationalString(text="Age", lang="en"))
q2.labels.append(InternationalString(text="Self-rated health", lang="en"))
q3.labels.append(InternationalString(text="Hours of sleep", lang="en"))

print(f"Constats de lint : {len(doc.lint())}")  # -> Constats de lint : 0
doc.save("well-being.xml")

    Les trois avertissements étaient « Maintainable element is missing a label. », un par question. Un libellé corrige chacun d'eux.

    Exercice 4

    q1.question_texts.append(InternationalString(text="Quel est votre âge ?", lang="fr"))
q1.labels.append(InternationalString(text="Âge", lang="fr"))

print(f"Questions: {len(doc.questions)}")  # -> Questions: 3
print(f"Constats de lint : {len(doc.lint())}")  # -> Constats de lint : 0

    Le nombre reste à 3, car les deux traductions appartiennent à q1. Dans le XML, la première question se lit maintenant ainsi :

    <r:Label>
  <r:Content xml:lang="en">Age</r:Content>
  <r:Content xml:lang="fr">Âge</r:Content>
</r:Label>
<d:QuestionText>
  <d:LiteralText>
    <d:Text xml:lang="en" isPlainText="true">What is your age?</d:Text>
  </d:LiteralText>
  <d:LiteralText>
    <d:Text xml:lang="fr">Quel est votre âge ?</d:Text>
  </d:LiteralText>
</d:QuestionText>

    Quiz¶

    Question 1 (O1) : Vous exécutez doc = ddi.new_study(title='Sleep Survey') et obtenez une TypeError. Pourquoi ?

    B. ddi.new_study() exige à la fois title= et agency=. Le message d'erreur le dit : « missing 1 required keyword-only argument: 'agency' ».

    Question 2 (O1) : Après q1 = doc.add_question(text='What is your age?'), qu'est-ce que q1 ?

    C. doc.add_question() ajoute un élément question à l'étude et renvoie cet objet question. Le garder dans une variable vous permet de l'utiliser plus tard.

    Question 3 (O2) : Une étude a trois questions. Vous en ajoutez une quatrième avec doc.add_question(), puis exécutez print(len(doc.questions)). Qu'est-ce qui s'affiche ?

    A. doc.questions est la liste de toutes les questions de l'étude, et len() les compte : trois plus la nouvelle.

    Question 4 (O3) : Vous ouvrez le fichier écrit par doc.save('well-being.xml'). Où trouvez-vous le texte de votre première question ?

    A. doc.save() écrit toute l'étude, et le texte de chaque question se trouve dans <d:Text>, à l'intérieur de <d:LiteralText>, lui-même dans <d:QuestionText>.

    Question 5 (O4) : Vous voulez la première question, q1, en anglais et en français. Quelle ligne le fait ?

    C. Ajouter un InternationalString avec la nouvelle langue stocke les deux versions dans le même élément question. L'option A crée une toute nouvelle question séparée, pas une traduction de q1.

    Question 6 (O5) : doc.validate() renvoie une liste vide, mais doc.lint() signale des avertissements. Le document est-il du DDI valide ?

    D. Une liste vide renvoyée par doc.validate() signifie que le document respecte le schéma DDI. Les avertissements de lint méritent d'être corrigés, mais ils ne rendent pas le document invalide.

    Question 7 (O5) : doc.lint() signale 'Maintainable element is missing a label.' une fois pour chacune de vos trois questions. Quelle modification fait disparaître les avertissements ?

    B. L'avertissement nomme le problème : les questions n'ont pas de libellé. Sauvegarder ou valider ne modifie pas le document, et ajouter de nouveau les questions avec le même code ramène les mêmes avertissements.

    Module 4 : Ajouter des variables et les associer aux questions¶

    Exercices¶

    Exercice 1

    Par exemple : « Une variable est une colonne d'un fichier de données, comme SleepHours, qui contient la réponse de chaque étudiant à la même question : combien d'heures il dort par nuit. »

    Exercice 2

    import ddi_l as ddi

doc = ddi.new_study(title="Student Well-Being Survey", agency="university.edu")

q1 = doc.add_question(text="What is your age?", label="Age")
q2 = doc.add_question(text="How would you rate your health?", label="Self-rated health")
q3 = doc.add_question(
    text="How many hours do you sleep per night?", label="Hours of sleep"
)

v1 = doc.add_variable(name="Age", label="Age in years", question=q1)
v2 = doc.add_variable(
    name="HealthRating", label="Self-rated health, 1 to 5", question=q2
)
v3 = doc.add_variable(name="SleepHours", label="Hours of sleep per night", question=q3)

print(f"Problèmes de schéma : {len(doc.validate())}")  # -> Problèmes de schéma : 0
print(f"Constats de lint : {len(doc.lint())}")  # -> Constats de lint : 0

    Si doc.lint() signale « Maintainable element is missing a label. », l'une de vos questions ou variables n'a pas de label=.

    Exercice 3

    print(f"Variables: {len(doc.variables)}")  # -> Variables: 3
for v in doc.variables:
    print(v.identifier)

    Chaque identifiant est un UUID, par exemple a1b2c3d4-....

    Exercice 4

    Par exemple : « Le lien mène à la question "How would you rate your health?", donc mon collègue sait que les valeurs sont l'évaluation que chaque étudiant fait de sa propre santé. Sans ce lien, il pourrait se tromper, par exemple en croyant que les valeurs ont été mesurées par un médecin, ou que 1 correspond à la meilleure santé. »

    Exercice 5

    doc.save("well-being.xml")
print(q1.identifier)

    Le nom de la variable se trouve dans <l:VariableName> :

    <l:VariableName>
  <r:String xml:lang="en">Age</r:String>
</l:VariableName>

    Le <r:ID> dans le <r:QuestionReference>, quelques lignes plus bas, est le même identifiant que celui qu'affiche print(q1.identifier). Cet identifiant commun est le lien entre la variable et la question.

    Quiz¶

    Question 1 (O1) : Dans un tableau avec les colonnes Age, HealthRating et SleepHours, lequel de ces éléments est une variable ?

    C. Une variable est comme une colonne. Chaque colonne contient un type d'information, comme une évaluation de la santé, pour chaque personne du jeu de données. Une ligne est une personne ; une valeur est une réponse.

    Question 2 (O2) : Que se passe-t-il quand vous exécutez doc.add_variable(name='Age', question='What is your age?') ?

    B. question= a besoin de l'objet renvoyé par doc.add_question(). Une simple chaîne n'est pas une question : l'appel échoue avec une AttributeError. Passez plutôt q1.

    Question 3 (O2) : Que fait question=q2 dans doc.add_variable(name='HealthRating', question=q2) ?

    A. L'argument question= enregistre un lien entre la variable et la question qui a collecté les données. Vous le voyez dans le XML sous la forme de <r:QuestionReference>.

    Question 4 (O3) : Quel code affiche l'identifiant de chaque variable de l'étude ?

    D. doc.variables est une liste : vous la parcourez et affichez l'identifier de chaque variable. L'option A échoue, car une liste n'a pas d'identifier, et l'option C parcourt les questions, pas les variables.

    Question 5 (O4) : Un utilisateur des données voit la colonne SleepHours et veut savoir exactement ce qui a été demandé. En quoi le lien entre la variable et sa question l'aide-t-il ?

    B. C'est la traçabilité : le lien mène l'utilisateur de la colonne de données jusqu'à la question exacte qui a collecté les données.

    Question 6 (O5) : Dans le XML sauvegardé, quel élément associe une variable à la question qui l'a collectée ?

    C. <r:QuestionReference> se trouve dans l'élément <l:Variable> et contient l'identifiant de la question. <l:VariableName> contient le nom de la variable, et <d:QuestionText> appartient à la question elle-même.

    Module 5 : Organiser avec les concepts et les univers¶

    Exercices¶

    Exercice 1

    • Nutrition : concept.
    • Adultes de 18 ans et plus au Canada : univers.
    • Qualité du sommeil : concept.
    • Écoles publiques de l'Ontario : univers.
    • Emploi : concept.
    • Enfants de 6 à 11 ans vivant dans des ménages privés : univers.

    Un concept est l'idée que mesure une variable, comme « Nutrition ». Un univers est le groupe de personnes ou de choses que couvre une étude, comme « Adultes de 18 ans et plus au Canada ».

    Exercice 2

    import ddi_l as ddi

doc = ddi.new_study(title="National Health Survey", agency="health.gc.ca")

demo = doc.add_concept(name="Demographics")
activity = doc.add_concept(name="Physical Activity")
nutrition = doc.add_concept(name="Nutrition")

doc.add_universe(name="Adults aged 18+ in Canada")

print(f"Concepts: {len(doc.concepts)}")  # -> Concepts: 3
print(f"Universes: {len(doc.universes)}")  # -> Universes: 1

    Exercice 3

    q1 = doc.add_question(text="How old are you?")
q2 = doc.add_question(text="What is your weight in kg?")
q3 = doc.add_question(text="How many days per week do you exercise?")
q4 = doc.add_question(text="How many servings of fruit do you eat per day?")

doc.add_variable(name="Age", question=q1, concept=demo)
weight = doc.add_variable(name="Weight", question=q2, concept=demo)
doc.add_variable(name="ExerciseFrequency", question=q3, concept=activity)
doc.add_variable(name="FruitServings", question=q4, concept=nutrition)

linked = weight.concept_references[0].identifier == demo.identifier

print(f"Questions: {len(doc.questions)}")  # -> Questions: 4
print(f"Variables: {len(doc.variables)}")  # -> Variables: 4
print(f"Weight is linked to Demographics: {linked}")
print(f"Schema problems: {len(doc.validate())}")  # -> Schema problems: 0

    Exercice 4

    print("Concepts:")
for concept in doc.concepts:
    print(f"  {concept.names[0].text}")

print("Universes:")
for universe in doc.universes:
    print(f"  {universe.names[0].text}")

    Quiz¶

    Question 1 (O1) : Quelle phrase est l'univers de cette étude ?

    A. L'univers dit qui est étudié. « Qualité du sommeil » et « Stress » disent ce qui est mesuré : ce sont des concepts. Une question n'est ni l'un ni l'autre.

    Question 2 (O1) : Quelle phrase explique correctement un concept ?

    C. Un concept est une idée abstraite que mesurent des variables. L'option A décrit un univers et l'option B, une liste de codes.

def add_codes(doc, code_list, labels):
    """Ajoute une Category et un Code par libellé, numérotés à partir de 1."""
    for number, label in enumerate(labels, start=1):

                agency=code_list.agency,
                identifier=str(uuid4()),
                version=code_list.version,
                value=str(number),
                category=category.to_reference(),
            )
